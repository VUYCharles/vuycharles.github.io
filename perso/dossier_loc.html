Filigrane locatif

python • 2026

Outil en ligne de commande qui applique un filigrane personnalisé sur les documents d'un dossier de location. Le texte inclut le nom du destinataire et l'URL de l'annonce, ce qui lie chaque PDF à un contexte précis.

Les fichiers originaux restent intacts dans un dossier séparé. Le script produit une copie filigranée dans un dossier nommé d'après le destinataire, prête à l'envoi.

Langage : Python 3
Dépendances : pypdf, reportlab, click
Interface : CLI
Usage : dossier original → sortie filigranée
